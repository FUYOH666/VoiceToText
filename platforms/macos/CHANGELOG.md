# Changelog

Все важные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.2.0] - 2026-01-18

### Added
- **quickmachotkey>=2025.7.28**: Добавлена новая зависимость для надежной работы глобальных горячих клавиш на macOS.
- **Тесты для горячих клавиш**: Добавлен `tests/test_hotkeys.py` для проверки работы системы горячих клавиш.

### Changed
- **Миграция на quickmachotkey для глобальных горячих клавиш**: Заменена нестабильная реализация на основе `pynput` на надежное решение `quickmachotkey`, использующее нативные macOS API. Это устраняет проблемы с "застреванием" модификаторов после автовставки и обеспечивает долгосрочную стабильность работы горячих клавиш.
- Упрощена логика обработки горячих клавиш: удалены все workaround'ы для `pynput` (фильтрация injected событий, синхронизация состояния модификаторов, мониторинг застрявших клавиш).
- Убрана необходимость очистки состояния горячих клавиш после автовставки - `quickmachotkey` работает на системном уровне и не подвержен проблемам с injected событиями.
- Улучшена обработка ошибок в `PermissionsChecker` и `TextInjector` - приложение продолжает работу даже при отсутствии некоторых PyObjC модулей.

### Removed
- Методы `_sync_modifier_state()`, `_clear_pressed_keys()`, `_monitor_stuck_keys()`, `_darwin_intercept()` из `HotkeyManager`.
- Логика множественной очистки состояния горячих клавиш после автовставки в `main.py`.
- Зависимость от `pynput` для глобальных горячих клавиш (оставлена временно в `requirements.in` для обратной совместимости, будет удалена в следующей версии).

### Fixed
- Исправлена проблема "застревания" горячих клавиш после автовставки текста.
- Устранена необходимость в периодической синхронизации состояния модификаторов с системой.
- Упрощена архитектура обработки горячих клавиш для повышения надежности.
- Исправлена обработка ошибок при отсутствии PyObjC модулей - приложение больше не завершается при их отсутствии.

[1.2.0]: https://github.com/FUYOH666/VoiceToText/tree/main/platforms/macos

## [1.0.0] - 2025-11-03

### Added
- Первый релиз VTTv2 с поддержкой MLX Whisper
- Автоматическая загрузка моделей MLX из Hugging Face Hub
- Оптимизация для MacBook Air M1 с 8GB RAM
- Поддержка MLX Whisper как основного движка транскрипции
- Примеры конфигураций для M1 8GB и M4 128GB
- Автовставка текста в место курсора через macOS API
- Глобальные горячие клавиши (Option+Space)
- Полная документация (README, QUICKSTART, CONTRIBUTING)
- Health check команда для проверки системы
- Поддержка русского языка
- **Автоматические тесты** (pytest) - 29 тестов покрывающих основные функции
- **CI/CD** (GitHub Actions) - автоматическая проверка кода при каждом коммите
- **Линтинг и форматирование** (ruff) - автоматическая проверка стиля кода
- **Версионирование** - CHANGELOG.md и Semantic Versioning

### Changed
- Переход с whisper.cpp на MLX Whisper как основной движок
- Упрощенная установка без компиляции C++
- Автоматическая загрузка моделей вместо ручного скачивания

### Fixed
- Проблемы с инициализацией на некоторых конфигурациях
- Неэффективное использование памяти на M1 8GB

[1.0.0]: https://github.com/FUYOH666/VoiceToText-MLX-M1-8Gb/releases/tag/v1.0.0

## [1.1.0] - 2026-01-18

### Fixed
- **Критическое исправление автовставки текста**: Убрана пометка CGEvent событий как injected, что позволяло приложениям их игнорировать
- **Исправлена стабильность горячих клавиш**: Добавлена фильтрация injected событий через darwin_intercept для предотвращения конфликтов с событиями вставки
- **Улучшена логика определения активного приложения**: Активное приложение определяется непосредственно перед вставкой, а не заранее, что решает проблему переключения между приложениями
- **Исправлен механизм выполнения автовставки**: Заменен rumps.Timer на комбинацию threading.Thread + AppHelper.callAfter для более надежного выполнения в главном потоке

### Changed
- Улучшена надежность автовставки: увеличены задержки между этапами для гарантии активации приложения
- Добавлено подробное логирование процесса автовставки для диагностики проблем
- Оптимизированы задержки: уменьшены с 0.8 до 0.5 секунды после улучшения логики определения активного приложения

### Removed
- Удалены неиспользуемые импорты из text_injector.py (CGEventSetIntegerValueField, kCGEventSourceUserData, VTT2_INJECTED_EVENT_MARKER и др.)

### Documentation
- Обновлены ссылки на репозиторий: указан правильный путь `platforms/macos` в основном репозитории VoiceToText
- Обновлена документация по устранению проблем с автовставкой
- Актуализированы README.md и QUICKSTART.md с правильными командами клонирования
