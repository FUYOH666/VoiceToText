## 🎯 О чем этот проект?

VTTv2 - это бесплатное локальное приложение для преобразования речи в текст на macOS. В отличие от платных аналогов, оно работает **полностью офлайн**, все ваши данные остаются на вашем Mac и никогда не отправляются в облако.

### Какая проблема решена?

Многие приложения для транскрипции:
- ❌ Требуют подписку ($8-30/мес)
- ❌ Отправляют ваши аудио на серверы
- ❌ Работают только при наличии интернета
- ❌ Ограничивают возможности настройки

**Мы решили:** Создать полностью локальное решение с открытым исходным кодом, которое работает на вашем Mac без интернета и без ограничений.

## 🆚 Чем это отличается от предыдущей версии?

### Предыдущая версия (whisper.cpp)

В [старом репозитории](https://github.com/FUYOH666/VoiceToText-MACos) использовался **whisper.cpp** - C++ реализация Whisper с поддержкой Core ML и Metal.

**Проблемы whisper.cpp:**
- Требовал компиляцию C++ кода
- Нужно было вручную скачивать модели
- Проблемы с инициализацией на некоторых конфигурациях
- Менее эффективное использование памяти на Apple Silicon

### Текущая версия (MLX Whisper) ⭐

Теперь используется **MLX Whisper** - нативный фреймворк Apple для машинного обучения на Apple Silicon.

**Преимущества MLX Whisper:**
- ✅ Автоматическая загрузка моделей (один раз при первом использовании)
- ✅ Оптимизировано специально для Apple Silicon (M1/M2/M3/M4)

**Надежные горячие клавиши:**
- ✅ Использует `quickmachotkey` - нативные macOS API для глобальных горячих клавиш
- ✅ Стабильная работа без "застревания" модификаторов
- ✅ Работает на системном уровне, не подвержен проблемам с injected событиями
- ✅ Более эффективное использование памяти
- ✅ Проще в установке - не требует компиляции C++
- ✅ Работает стабильнее на разных конфигурациях
- ✅ Модель кэшируется локально после первой загрузки

## 🛠️ Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/FUYOH666/VoiceToText.git
cd VoiceToText/platforms/macos
```

**Примечание:** Проект находится в поддиректории `platforms/macos` основного репозитория [VoiceToText](https://github.com/FUYOH666/VoiceToText).

### 2. Установка Python зависимостей

```bash

python3.12 -m venv venv

# Активация venv
source venv/bin/activate

# Обновление pip
pip install --upgrade pip==25.3

# Установка зависимостей (включая MLX Whisper)
pip install -r requirements.txt
```

**Примечание:** MLX Whisper автоматически скачает модель `mlx-community/whisper-medium` при первом использовании (требуется интернет только один раз). Это оптимальный выбор для M1 с 8GB RAM.

### 3. Настройка разрешений macOS

**ВАЖНО:** Перед запуском нужно настроить разрешения:

1. **Микрофон:**
   - Системные настройки > Конфиденциальность > Микрофон
   - Добавьте Terminal (или приложение, которое запускает VTTv2)

2. **Accessibility (Управление компьютером):**
   - Системные настройки > Конфиденциальность > Управление компьютером
   - Добавьте Terminal (или приложение, которое запускает VTTv2)

## ⚙️ Конфигурация

Основной файл конфигурации: `config.yaml`

**Текущая конфигурация по умолчанию:** Оптимизирована для MacBook Air M1 с 8GB RAM.

### Примеры конфигураций для разных MacBook

В репозитории есть примеры конфигураций:

- **`config.m1-8gb.yaml.example`** - MacBook Air M1 (8GB RAM) с MLX Whisper Medium ⭐
- **`config.m4-128gb.yaml.example`** - MacBook Pro M4 (128GB RAM) с MLX Whisper Large V3

Чтобы использовать пример конфигурации:

```bash
# Для M1 8GB (по умолчанию)
cp config.m1-8gb.yaml.example config.yaml

# Для M4 128GB
cp config.m4-128gb.yaml.example config.yaml
```

### Основные параметры

**MLX Whisper (основной движок):**
- `transcription.engine` - должен быть `"mlx_whisper"`
- `transcription.mlx_whisper.model_name` - модель MLX:
  - `"mlx-community/whisper-medium"` - для M1 8GB ⭐
  - `"mlx-community/whisper-large-v3"` - для M4 128GB (максимальная точность)
- `transcription.mlx_whisper.language` - язык (`ru` для русского)

**Производительность:**
- `performance.memory_limit_mb` - лимит памяти (4096 для M1 8GB, 32768 для M4 128GB)

**UI:**
- `ui.hotkey` - горячие клавиши (по умолчанию: `"option+space"`)
- `ui.auto_paste_enabled` - автовставка текста (`true`)

## 📝 Как это работает?

### Архитектура решения

1. **Запись аудио** - записываем звук с микрофона через `sounddevice`
2. **Обработка** - нормализуем аудио для MLX Whisper
3. **Транскрипция** - MLX Whisper обрабатывает аудио локально на вашем Mac
4. **Автовставка** - текст автоматически вставляется в место курсора через macOS API

### Почему MLX Whisper?

**MLX (Machine Learning eXchange)** - это фреймворк Apple специально разработанный для Apple Silicon. Он:
- Использует Unified Memory Architecture (UMA) для эффективной работы с памятью
- Оптимизирован для Neural Engine и GPU на Apple Silicon
- Автоматически управляет памятью и вычислениями
- Работает быстрее чем универсальные решения типа whisper.cpp

### Что происходит при транскрипции?

1. **Первое использование** (требуется интернет):
   - MLX Whisper скачивает модель из Hugging Face Hub
   - Сохраняет в локальный кэш: `~/.cache/huggingface/hub/`
   - Размер модели Medium: ~977 MB

2. **Все последующие запуски** (полностью офлайн):
   - Модель загружается из локального кэша
   - Обработка аудио происходит 100% локально на вашем Mac
   - Никаких обращений к интернету
   - Ваши данные не покидают ваш Mac

## ❓ Частые проблемы

### 1. Модель не скачивается

**Симптомы:** При первом запуске модель не загружается

**Решение:**
- Убедитесь что есть интернет при первом использовании
- Проверьте логи приложения для деталей
- Модель скачивается только один раз, затем работает офлайн

### 2. Разрешение на микрофон отклонено

**Ошибка:** `❌ Разрешение на микрофон отклонено`

**Решение:**
- Системные настройки > Конфиденциальность > Микрофон
- Добавьте Terminal или приложение в список разрешенных
- Перезапустите приложение

### 3. Разрешение Accessibility не предоставлено

**Ошибка:** `❌ Разрешение Accessibility не предоставлено`

**Решение:**
- Системные настройки > Конфиденциальность > Управление компьютером
- Добавьте Terminal или приложение в список разрешенных
- Перезапустите приложение

### 4. Автовставка не работает

**Симптомы:** Текст транскрибируется, но не вставляется

**Решение:**
- Проверьте разрешение Accessibility (см. выше)
- Проверьте настройку `ui.auto_paste_enabled: true` в `config.yaml`
- Проверьте логи приложения для деталей
- Убедитесь, что приложение, в которое нужно вставить текст, активно в момент вставки
- Автовставка определяет активное приложение перед вставкой, поэтому переключение между приложениями во время транскрипции не должно вызывать проблем
