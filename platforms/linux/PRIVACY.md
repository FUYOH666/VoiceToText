# Конфиденциальность и очистка данных

## Автоматическая очистка

F9 ASR **не сохраняет** ваши голосовые записи и транскрипции. Все данные обрабатываются временно и автоматически удаляются.

### Что происходит с данными:

1. **Временные аудио файлы** (`/tmp/f9-asr-recordings/`):
   - ✅ Удаляются **сразу после транскрипции**
   - ✅ Автоматически очищаются при старте (файлы старше 24 часов)
   - ✅ Хранятся только в оперативной памяти системы (`/tmp`)

2. **Debug файлы** (только при ошибках):
   - Сохраняются только при пустом результате транскрипции
   - Автоматически ограничиваются до **последних 5 файлов**
   - Старые debug файлы удаляются автоматически

3. **Транскрипции**:
   - ✅ **Не сохраняются** нигде
   - ✅ Только копируются в буфер обмена
   - ✅ Не отправляются никуда кроме вашего ASR сервиса

4. **Логи**:
   - Хранятся в systemd journal (стандартное место для логов Linux)
   - Содержат только техническую информацию (не полные транскрипции)
   - Автоматически ротируются системой

## Настройка очистки

В `config.yaml` можно настроить:

```yaml
audio:
  # Автоматическая очистка старых файлов (в часах)
  # 0 = отключено, 24 = удалять файлы старше 24 часов
  cleanup_max_age_hours: 24
```

## Ручная очистка

Если нужно очистить все временные файлы вручную:

```bash
# Удалить все временные файлы
rm -rf /tmp/f9-asr-recordings/*

# Проверить размер
du -sh /tmp/f9-asr-recordings/
```

## Конфиденциальность

- ✅ **100% локальная обработка** - все данные остаются на вашем компьютере
- ✅ **Нет отправки в облако** - транскрипция выполняется вашим локальным ASR сервисом
- ✅ **Нет истории использования** - никаких логов транскрипций не сохраняется
- ✅ **Автоматическая очистка** - все временные файлы удаляются автоматически

## Проверка

Проверить, что очистка работает:

```bash
# Посмотреть текущие файлы
ls -lh /tmp/f9-asr-recordings/

# Проверить размер
du -sh /tmp/f9-asr-recordings/

# После использования F9 файлы должны автоматически удалиться
```

## Стабильность

Сервис настроен на:
- ✅ **Автоматический перезапуск** при сбоях (через systemd)
- ✅ **Автоматическую очистку** старых файлов при старте
- ✅ **Ограничение debug файлов** (максимум 5)
- ✅ **Очистку после каждой транскрипции**

При постоянном использовании (даже неделями) файлы **не будут накапливаться** благодаря автоматической очистке.
