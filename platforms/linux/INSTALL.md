# Инструкция по установке и использованию

## Быстрый старт

### 1. Установка системных зависимостей

```bash
sudo apt update
sudo apt install -y alsa-utils libnotify-bin xclip
```

### 2. Установка Python зависимостей

```bash
cd /path/to/F9-asr  # Перейдите в директорию проекта
uv sync
```

### 3. Проверка ASR сервиса

Убедитесь, что ASR сервис запущен на порту 8001:

```bash
curl http://localhost:8001/healthz
```

### 4. Установка как systemd service (автозапуск)

**Рекомендуется:** Установить как systemd user service для постоянной работы:

```bash
./scripts/install-service.sh
```

Это установит приложение как фоновый сервис, который будет:
- ✅ Автоматически запускаться при входе в систему
- ✅ Автоматически перезапускаться при сбоях
- ✅ Работать постоянно в фоновом режиме
- ✅ Слушать горячую клавишу F9 автоматически

**Альтернатива:** Запуск вручную (не рекомендуется для постоянного использования):

```bash
uv run python -m f9_asr.main
```

### 5. Использование

После установки сервиса приложение уже работает в фоне. Просто нажмите **F9** для начала записи!

**Управление сервисом:**
```bash
# Проверить статус
systemctl --user status f9-asr.service

# Посмотреть логи (в реальном времени)
journalctl --user -u f9-asr.service -f

# Перезапустить
systemctl --user restart f9-asr.service

# Остановить
systemctl --user stop f9-asr.service

# Запустить
systemctl --user start f9-asr.service
```

## Использование

1. Нажмите **F9** - начнется запись (появится уведомление)
2. Говорите в микрофон
3. Нажмите **F9** снова - запись остановится и начнется транскрипция
4. Результат автоматически скопируется в буфер обмена
5. Вставьте текст куда нужно (Ctrl+V)

## Troubleshooting

### ASR сервис недоступен

```bash
# Проверьте статус сервиса
curl http://localhost:8001/healthz

# Если сервис не запущен, запустите его
# (команда зависит от вашей конфигурации)
```

### Микрофон не работает

```bash
# Проверьте доступные устройства
arecord -l

# Тест записи (3 секунды)
timeout 3 arecord -f S16_LE -r 16000 -c 1 /tmp/test.wav
aplay /tmp/test.wav  # Проверка воспроизведения
```

### Горячая клавиша не работает

1. Убедитесь, что приложение запущено
2. Проверьте, нет ли конфликтов с другими приложениями
3. Перезапустите GNOME: `Alt+F2` → `r` → `Enter`
4. Или перелогиньтесь

### Права доступа к клавиатуре

Если `pynput` не может захватить клавиатуру, может потребоваться:

```bash
# Для некоторых систем
sudo chmod 666 /dev/input/event*
```

Или добавьте пользователя в группу `input`:

```bash
sudo usermod -a -G input $USER
# Перелогиньтесь
```

## Конфигурация

Отредактируйте `config.yaml` для изменения настроек:

- **asr.base_url**: URL ASR сервиса (по умолчанию: http://localhost:8001)
- **asr.language**: Язык транскрипции (null для автоопределения)
- **hotkey.key**: Горячая клавиша (по умолчанию: f9)
- **ui.copy_to_clipboard**: Автоматическое копирование в буфер обмена
- **ui.show_notifications**: Показывать уведомления
