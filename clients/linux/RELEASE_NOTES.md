## v0.1.0 — Первый релиз

Система транскрипции голоса по нажатию клавиши F9 с использованием ASR сервиса.

## ✨ Основные возможности

- 🎤 **Запись голоса** по нажатию F9
- 🚀 **Интеграция с ASR сервисом** (Whisper Large v3 Turbo)
- 📋 **Автокопирование** результата в буфер обмена
- 🔔 **Уведомления** о статусе транскрипции
- 🧹 **Автоматическая очистка** временных файлов
- 🔒 **Конфиденциальность** - данные не сохраняются
- 🔄 **Стабильная работа** через systemd

## 📦 Что включено

- Python пакет с модульной архитектурой
- Systemd user service для автозапуска
- Скрипты установки и настройки
- Полная документация (8 файлов)
- Конфигурация через YAML

## 🚀 Быстрый старт

```bash
git clone <repository-url>
cd F9-asr
sudo apt install -y alsa-utils libnotify-bin xclip
uv sync
./scripts/install-service.sh
# Готово! Нажмите F9 для начала записи
```

1. Использует существующий ASR сервис вместо локального whisper.cpp

3. Гибкая конфигурация через YAML
4. Лучшая обработка ошибок
5. Проще в поддержке (чистый Python)
