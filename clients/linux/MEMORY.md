# Управление памятью F9 ASR

## Текущее потребление памяти

F9 ASR использует **очень мало памяти**:

- **Текущее использование**: ~36-40 MB
- **Пиковое использование**: ~40 MB
- **Процент от общей памяти**: ~0.06% (при 60GB RAM)

## Ограничения памяти в systemd

Сервис настроен с ограничениями памяти для предотвращения утечек:

```ini
MemoryMax=200M      # Максимальная память (жесткий лимит)
MemoryHigh=150M     # Мягкий лимит (предупреждение)
MemoryLimit=200M    # Лимит для OOM killer
```

Если сервис превысит 200MB, systemd автоматически перезапустит его.

## Оптимизации памяти

### 1. Streaming запросов

- Файлы отправляются потоком (streaming), не загружаются целиком в память
- Ответы API обрабатываются потоком

### 2. Автоматическая очистка

- Временные файлы удаляются сразу после транскрипции
- Большие объекты удаляются из памяти после использования
- Debug файлы ограничены до 5 штук

### 3. Ограничение размеров

- Уведомления ограничены до 100 символов
- Логирование ответов ограничено (preview только)

## Мониторинг памяти

### Проверка текущего использования

```bash
# Статус через systemd
systemctl --user status f9-asr.service | grep Memory

# Детальная информация
systemctl --user show f9-asr.service | grep Memory

# Через ps
ps aux | grep f9_asr | awk '{print $6/1024 "MB"}'
```

### Проверка утечек памяти

```bash
# Мониторинг в реальном времени
watch -n 5 'systemctl --user status f9-asr.service | grep Memory'

# Логи использования памяти
journalctl --user -u f9-asr.service | grep -i memory
```

## Настройка ограничений

Если нужно изменить лимиты памяти, отредактируйте `scripts/f9-asr.service`:

```ini
# Более строгие лимиты (если нужно)
MemoryMax=100M
MemoryHigh=80M
MemoryLimit=100M
```

Затем перезагрузите:
```bash
systemctl --user daemon-reload
systemctl --user restart f9-asr.service
```

## Типичное потребление памяти

- **Базовое использование**: ~35-40 MB
- **Во время записи**: +5-10 MB (буферы аудио)
- **Во время транскрипции**: +10-20 MB (обработка ответа API)
- **После транскрипции**: возврат к базовому уровню

## Сравнение с другими приложениями

- **F9 ASR**: ~36 MB
- **Браузер (Chrome)**: ~500-2000 MB
- **IDE (VS Code)**: ~200-500 MB
- **Терминал**: ~50-100 MB

F9 ASR потребляет **в 10-50 раз меньше** памяти чем типичные приложения!

## Если память растет

Если заметили рост памяти:

1. Проверьте логи на ошибки:
   ```bash
   journalctl --user -u f9-asr.service -f
   ```

2. Проверьте временные файлы:
   ```bash
   du -sh /tmp/f9-asr-recordings/
   ls -lh /tmp/f9-asr-recordings/ | wc -l
   ```

3. Перезапустите сервис:
   ```bash
   systemctl --user restart f9-asr.service
   ```

4. Если проблема сохраняется, проверьте systemd лимиты:
   ```bash
   systemctl --user show f9-asr.service | grep Memory
   ```

## Вывод

F9 ASR **не пожирает память** - это легковесное приложение с минимальным потреблением (~36MB). Ограничения памяти в systemd гарантируют, что даже при утечках сервис будет автоматически перезапущен.
