# Contributing to F9 ASR

Спасибо за интерес к проекту! Мы приветствуем вклад в развитие F9 ASR.

## Разработка

### Настройка окружения

```bash
# Клонировать репозиторий
git clone <repository-url>
cd F9-asr

# Установить зависимости
uv sync --dev

# Запустить в режиме разработки
uv run python -m f9_asr.main
```

### Структура проекта

```
F9-asr/
├── src/f9_asr/          # Исходный код
│   ├── config.py        # Конфигурация
│   ├── audio_recorder.py # Запись аудио
│   ├── asr_client.py    # ASR API клиент
│   ├── hotkey_handler.py # Обработчик горячей клавиши
│   └── main.py          # Точка входа
├── scripts/             # Скрипты установки
├── config.yaml          # Конфигурация по умолчанию
└── docs/                # Документация
```

## Правила разработки

1. **Используйте относительные пути** - все пути должны быть относительными или определяться динамически
2. **Следуйте Engineering Charter** - см. правила в `.cursor/rules/`
3. **Используйте `uv`** для управления зависимостями
4. **Валидация через Pydantic** - все конфигурации через Pydantic Settings
5. **Структурированное логирование** - используйте `logging`, не `print`
6. **Тесты** - добавляйте тесты для новой функциональности

## Коммиты

Используйте понятные сообщения коммитов:

```
feat: добавить автоматическую очистку старых файлов
fix: исправить обработку пустых ответов API
docs: обновить документацию по установке
```

## Pull Requests

1. Создайте ветку от `main`
2. Внесите изменения
3. Убедитесь, что все работает
4. Обновите документацию при необходимости
5. Создайте Pull Request с описанием изменений

## Вопросы

Если у вас есть вопросы, создайте Issue в репозитории.
